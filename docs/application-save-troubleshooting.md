# 企業情報の保存失敗（2026-10-17）

## 原因と対応

実環境の `applications_application_type_check` は、夏インターン・本選考・内定者インターンの3種類だけを許可していた。アプリから冬インターンを保存するとDB制約に違反する状態だった。

`0014_expand_application_types.sql` と同じトランザクションを適用し、既存3種類を維持したまま冬インターン・早期選考を追加した。反映後にDB制約の5種類を確認し、ユーザーが入力済みの企業情報を再保存して成功を確認した。DBの既存データとアクセス制御は維持している。

## エラー表示

Supabaseのエラーが通常のオブジェクトとしてthrowされた場合、`instanceof Error` に一致せず、原因が汎用メッセージに置き換わっていた。保存画面ではエラーコードを分類し、DB移行未適用・権限・入力・更新対象不在などの案内を表示するようにした。

DBが返す生の行データや内部の詳細は表示しない。失敗時はフォームを閉じず、入力内容を保持する。
