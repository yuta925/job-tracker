# 就活サイト・自己分析画面のUI（2026-10-17）

現在の青系の配色とMaterial Designのトークンを維持し、配置と使いやすさを改善する。

## 就活サイト

- ページ見出しと追加ボタン、カテゴリ別件数と絞り込み、サイト名・URL・メモの検索を配置する。
- カードにサイト名、ドメイン、カテゴリ、メモ、サイトを開くリンクを表示する。
- 編集・削除はホバーに依存せず常時表示する。URL未登録・不正なURLの場合も編集できる。
- 未登録と検索結果なしを区別し、検索条件の解除を用意する。

## 自己分析

- 強み・弱み・エピソードの件数を表示し、種類とタイトル・本文・タグで絞り込める。
- 本文の抜粋とタグを最初から表示し、長文は全文表示に切り替える。短い文章は切り捨てない。
- 本文展開と編集・削除は独立したボタンとし、ボタンの入れ子を解消する。
- 空のカテゴリには記入のきっかけになる問いを表示する。

## CSS適用漏れの修正

一覧で使用する `collection-*` のCSS定義が抜けていたため、ページ余白、カード、検索欄、絞り込み、タグ、操作ボタン、空状態を共通定義した。自己分析フォームと検索欄の未定義クラス `md-input` は既存の `md-field-input` に統一した。

一覧はPCで3列、中間幅で2列、700px以下で1列になる。320px幅でも本文・検索欄・ボタンが横にはみ出さないこと、自己分析の入力フォームの枠線・余白・文字サイズをブラウザで確認した。

検索とカテゴリの組み合わせ、条件解除、タグ検索、本文展開と編集操作をコンポーネントテストで確認する。実アカウントの保存・削除は検証のために行わない。
